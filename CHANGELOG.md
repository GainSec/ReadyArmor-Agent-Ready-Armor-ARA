# Release notes

## 0.1.0

ARA provides external supervision for agent runtimes.
The release includes the following functions:

- Bulwark resource rules and approval decisions.
- Native and Node runtime guards.
- Model traffic inspection and ABSOLUTE projection.
- Armory operator pages and token authentication.
- Armor, Weapon, Trim, and Temper equipment.
- Forge manifests, extraction, synthesis, and sealing.
- Domain packs and alphabet definitions.
- Persistent Hermes task runs and channel controls.
- Evidence references, findings, leads, and audit verification.
- Claude Code and OpenClaw launch adapters.

See the [product overview](README.md) for installation and operation.
