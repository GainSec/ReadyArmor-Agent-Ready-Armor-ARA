# Weapons and Forge

Forge turns selected source materials into reviewed reusable capability.
A session creates a weapon or a domain Pack.

## Authoring stages

```text
DEPOSIT → MANIFEST → REVIEW → EXHAUST → REVIEW
        → SYNTHESIZE → REVIEW → SEAL → SEALED
```

Deposits preserve source identity.
Manifest elements identify the included units for extraction.
Typed extraction events cite those elements.
Synthesis organizes the events into a draft and projected vocabularies.
Seal checks the applicable target, coverage, citation, and alphabet conditions.

## Weapon artifacts

A weapon can include procedures, knowledge shapes, fact schemas, stores, resource intent, scope lines, and policy material.
Generated chunks define the runtime phase graph and channel surface.
Projected alphabets supply domain vocabulary and related validator information.
The artifact also includes its search index, channel catalog, and seal metadata where generated.

## Retrieval and review

The default search path uses SQLite FTS5 and configured synonyms.
The operator runs retrieval calibration explicitly against representative expected results.
Seal copies an available query file for that later command.

Equipment merges marked weapon policy sections into the live files.
The supervisor mounts the runtime graph during engagement installation.
An active task checks equipment hashes before further target activity.

Reforge records typed changes against a predecessor weapon for review and approval.
