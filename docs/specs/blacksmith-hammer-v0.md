# Blacksmith and Hammer authoring loadout

Blacksmith armor supplies the persistent restrictions for weapon authoring.
The Blacksmith Hammer supplies the associated capability and policy overlay.
Forge selects this specialized pair for the weapon extraction path.

## Source and extraction

The active Forge manifest identifies the selected materials and element identities.
The authoring worker reads those elements through the available material tools.
Typed extraction calls submit structured bodies with their source identifiers.

The current Forge interface includes procedure, concept, fact-schema, store, resource, scope, and policy extraction channels.
The MCP mode determines the available tools for the current job.
Pack authoring uses Codex armor and the Pen with a different proposal surface.

## Output and review

Extraction events preserve their manifest element identifiers.
Coverage accounts for the included elements.
Synthesis organizes the events into a weapon draft.
The operator examines the draft before seal.

Seal applies the configured target, citation, coverage, and alphabet checks.
The force option can accept designated soft coverage conditions.
Hard target and citation requirements continue to apply.

## Equipment lifecycle

The creation session records the prior equipment identities.
The CLI's creation and cleanup paths manage the specialized authoring equipment and prior selection.
A sealed weapon later adds its policy through marked overlay sections.
A supervised engagement mounts the selected runtime graph at installation.

The operator verifies retrieval explicitly through the calibration command.
The stored seal and search artifacts provide the inputs for that check.
